## Progetti

### KPI Automation & CAN Control

Strumento professionale sviluppato in **Python** per automatizzare la misurazione delle KPI delle applicazioni a ogni rilascio.

Il sistema permette di interagire con l'hardware automotive attraverso **python-CAN**, controllando centraline **ETM ed ECU** tramite strumenti **Vector** e canali CAN virtualizzati.

**Tecnologie principali**

`Python` · `python-CAN` · `CAN` · `Vector` · `ETM` · `ECU` · `Automazione`

---

### GitHub Repository Explorer

Applicazione Android sviluppata in **Kotlin** per esplorare i repository e il profilo GitHub dell'utente.

Funzionalità principali:

- Login tramite GitHub OAuth
- Visualizzazione dei repository
- Dettagli e statistiche dei repository
- Visualizzazione del profilo GitHub
- Integrazione con GitHub API
- Architettura MVVM
- Chiamate API tramite Retrofit

**Tecnologie principali**

`Kotlin` · `Android` · `Retrofit` · `GitHub OAuth` · `GitHub API` · `MVVM`
